Studium-Gmail-Import

Private Anwendung zur Übertragung von Nachrichten aus einem eigenen Hochschul-IMAP-Postfach in das eigene Gmail-Konto.

Zweck

Die Anwendung liest Nachrichten aus dem Hochschulpostfach über verschlüsseltes IMAP und importiert sie über die Gmail API. Neue Kopien werden mit dem Label „Studium / h_da“ versehen und außerhalb des allgemeinen Posteingangs abgelegt. Sie wird ausschließlich vom Betreiber für dessen eigenes Konto genutzt; es gibt keine öffentliche Registrierung.

Google-Zugriff

Die Anwendung verwendet den OAuth-Berechtigungsumfang gmail.modify für Import, Label-Zuordnung und technische Prüfung. Sie ist nicht für den Versand oder das Löschen vorhandener Gmail-Nachrichten vorgesehen.

Betrieb

Der aktuelle Import läuft auf einem privaten Windows-Rechner. Ein späterer Betrieb auf einem externen Server wird geplant, ist jedoch noch nicht eingerichtet.
